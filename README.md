# LIZA

(Local Intuitive Zoetropic Agent, or Lateral Intuitive Zoetropic Agent)

This begain as a bit of fun -- can I get local models to run the personae of a few of my agents with reasonable success.
Now that we're serious about it, it will need a proper design.

First pass will probably be testing the LittleCoder harness with Gemma4 versions. 
A good series of test cases would be writing programs suitable for an intro Python course,
and writing individual functions or libraries for higher level courses. 
The idea here is that making LIZA focus on specific tasks or problems, rather than "build this system",
is a better fit. We'll find out by trying.
